# Contributing to this Project

Thank you for your interest in improving this LV2 plugin! We welcome all forms of contributions.

## How to Contribute

### 1. Reporting Bugs
* Check the existing Issues to see if the bug has already been reported.
* If not, open a new Issue and describe the problem, your DAW, and steps to reproduce it.

### 2. Submitting Changes (Pull Requests)
1. Fork the repository.
2. Create a new branch for your feature or fix (`git checkout -b feature/my-feature`).
3. Make your changes in the Pascal source files inside the `src/` directory.
4. Test your changes locally using the `build_and_deploy.bat`.
5. Commit your changes and push them to your fork.
6. Open a Pull Request against the `main` branch.

## Code Style
* Keep the code clean and use standard Object Pascal / Free Pascal formatting.
* Do not change the core automation scripts (`build_and_deploy.bat` or `installer.iss`) without discussing it in an Issue first.
