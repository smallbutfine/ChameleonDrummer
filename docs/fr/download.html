ChameleonDrummer est disponible en exécutables compilés pour Windows. Le système est construit avec Free Pascal et Lazarus, ce qui le rend léger et autonome.

Télécharger v1.1.35 depuis GitHub

Exigences du système

  • Windows 10 ou supérieur (64 bits)
  • Free Pascal Compiler (FPC) 3.2.2+
  • Lazarus IDE (optionnel, pour le développement)
  • Minimum 2GB RAM

Installation

Pas d'installation requise. Téléchargez simplement l'exécutable et lancez-le. Le système est autonome.

Pour le développement, cloner le dépôt et exécuter:

lazbuild ChameleonDrummer.lpr

ou

lazbuild gui/chameleondrummer_gui.lpi
