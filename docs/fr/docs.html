Référence Rapide Format de Motif

Bloc Groove (config/grooves/<genre>.tab)

[rock verse intensity=0.20-0.60]
K  x... .... x... .... | x... .... x... ..x.
S  .... x... .... x... | .... x... .... x...
H  x.x. x.x. x.x. x.x. | x.x. x.x. x.x. x.x.
  • En-tête: [style kind intensity=low-high]
  • Instruments: K=batterie, S=caisse, H=hi-hat, HO=hi-hat ouvert, HP=pédale hi-hat, R=tom rack, RB=tom basse, C=crash, C2=deuxième crash, CH=china, SP=splash, T1-T4=toms
  • Pas: .=repos, x=hit, X=accent, o=douce, g=fantôme
  • Mesures: Séparées par |; espaces ignorés; lignes plus courtes se répètent

Bloc Fill (config/fills/<drummer>.tab)

[bonham_fill_short energy=0.3]
S ... ... ... xxx

Comment le Moteur Fonctionne (En Bref)

  1. Modèle de Motif — Chaque beat a position, instrument, vélocité, durée, flags ghost/accent
  2. Structure de Chanson — Sections avec motifs, fills, segments, offsets de groove
  3. Sélection Bar-par-Bar — Sélection aléatoire pondérée basée sur correspondance d'intensité
  4. Phases Macro — Établir → Maintenir → Construire → Tourner
  5. Fills — Insérés aux limites de section, énergie-coïncidente
  6. Humanisation — Jitter de timing, variation de vélocité, feel de swing
  7. Contraintes Physiques — Max 3 hits/pas, règles de coordination des membres
  8. Plugins de Batteur — 17 batteurs appliquent modifications spécifiques
  9. Système Keymap — JSON mappent noms de note vers notes MIDI (GM, AD2, EZD3, XG, custom)
  10. Export MIDI — SMF Format 0 avec événements tempo/mesure
