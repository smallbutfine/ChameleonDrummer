LES PRINCIPES DERRIÈRE LA GÉNÉRATION MIDI

De ComposerV2.pas, Pattern.pas, Song.pas, et MidiIO.pas — le code source révèle un pipeline structuré.

  1. Modèle de Motif — Pulses avec position, instrument, vélocité, flags ghost/accent.
  2. Structure de Chanson — Sections avec motifs, fills, segments et offsets de groove.
  3. Évolution Bar par Bar — Sélection aléatoire pondérée avec bandes d'intensité, phases macro, fills contextuels.
  4. Contraintes Physiques — Le correcteur de motifs élimine les hits impossibles.
  5. Humanisation — Variation de timing et vélocité pour le réalisme.
  6. Export MIDI — Événements VLQ-encodés avec métadonnées BPM/PPQ.

Step Editor

Le Step Editor (tools/step_editor/step_editor.exe) est une application GUI Lazarus autonome pour créer et éditer visuellement des motifs de batterie. Il fonctionne avec la GUI principale de ChameleonDrummer — vous pouvez l'ouvrir depuis le bouton Step Editor de la GUI principale, ou l'exécuter directement.

Aperçu

L'éditeur de pas affiche un motif de batterie sous forme de grille : les lignes sont les instruments de batterie, les colonnes sont les pas de temps. Cliquez sur les cellules pour activer/désactiver les coups. Des lignes verticales épaisses marquent les limites de mesure.

Flux de travail

  1. Charger un fichier MIDI: Cliquez sur Parcourir à côté du champ de fichier MIDI et sélectionnez un fichier .mid. Le fichier est automatiquement converti au format tab à l'aide de l'outil en ligne de commande midi_to_tab.exe et chargé dans la grille.
  2. Ou charger un fichier tab: Le navigateur de fichiers accepte également les fichiers .tab directement.
  3. Éditer le motif: Cliquez sur les cellules pour activer/désactiver les coups. Sélectionnez une colonne pour éditer un pas complet à la fois.
  4. Changer la mesure: Utilisez le menu déroulant Meter pour définir la signature rythmique (prend en charge les mesures standard et en triolets comme 4/4T, 6/8T).
  5. Changer le zoom: Utilisez le menu déroulant Zoom pour passer d'une résolution de grille de noires, croches, doubles-croches et triples-croches.
  6. Naviguer entre les pages: Utilisez Précédent et Suivant pour naviguer dans les pages du motif.
  7. Enregistrer comme groove ou fill: Sélectionnez le bouton radio Groove ou Fill, choisissez un style dans le menu déroulant, et cliquez sur Save Pattern As pour écrire le motif dans config/grooves/ ou config/fills/.

Convertisseur en ligne de commande

L'éditeur de pas utilise tools/midi_to_tab.exe en arrière-plan pour convertir les fichiers MIDI au format tab. Vous pouvez également l'exécuter directement:

midi_to_tab.exe input.mid [output.tab]
midi_to_tab.exe input.mid --fill --name bonham_fill --energy 0.6
midi_to_tab.exe input.mid --meter 7/8 --resolution 16
midi_to_tab.exe input.mid --mapping mappings/gm.json --style rock --kind verse

Chemins et configuration

L'éditeur de pas résout les chemins relatifs à son propre emplacement:

  • Exécutable: tools/step_editor/step_editor.exe
  • Convertisseur: midi_to_tab.exe dans le même répertoire
  • Styles: ..\..\config\styles.txt (deux niveaux au-dessus de tools/step_editor/)
  • Sortie grooves: ..\..\config\grooves\
  • Sortie fills: ..\..\config\fills\

    • Lorsqu'il est lancé depuis la GUI principale de ChameleonDrummer, l'éditeur de pas hérite du même répertoire de travail et de la même configuration.

    Mode sombre

    L'éditeur de pas prend en charge le mode sombre, assorti au thème sombre de la GUI principale. Il suit le thème du système par défaut et peut être basculé dans l'interface.
