ГЛАВНАЯКОНЦЕПЦИИРУКОВОДСТВОСКАЧАТЬENDEES

КАК CHAMELEONDRUMMER СОЗДАЕТ ВАШИ БАРАБАННЫЕ ТРЕКИ

Из ComposerV2.pas, Pattern.pas, Song.pas, и MidiIO.pas — исходный код раскрывает структурированный конвейер, который может понять любой музыкант.

  1. Модель паттерна — Такты с позицией, инструментом, скоростью, флагами призрачности/акцента.
  2. Структура песни — Секции с паттернами, филы, сегментами и смещениями грува.
  3. Эволюция бар за баром — Взвешенный случайный выбор паттернов с интенсивностными диапазонами, макрофазами, контекстными филы.
  4. Физические ограничения — Исправитель паттернов удаляет невозможные удары.
  5. Гуманизация — Вариации времени и скорости для реализма.
  6. Экспорт MIDI — VLQ-кодированные события с метаданными BPM/PPQ.

АРХИТЕКТУРНЫЕ ВОЗМОЖНОСТИ

MIDI-ДВИГАТЕЛЬ (НЕТ ЗАВИСИМОСТЕЙ)

Прямой бинарный писатель SMF Формат 0 • Кодирование VLQ • Корректные мета-события темпа/размера • Совместим со всеми DAW и VST барабанов

Генерация паттернов

8 шаблонов • Полные специфичные для жанра определения стилей (5 жанров × 8 стилей = 38 всего) • Блоки паттернов объявляют размер, интенсивность и строки инструментов

Плагины барабанщиков

Все 17 барабанщиков с полной поддержкой комбинируемых модификаций • BehindBeat, GhostNotes, LinearCoordination, ShuffleFeel, FillPatterns

Динамическая система Keymap

Нет жестко заданных MIDI нот в коде Pascal • Все разрешение нот проходит через template JSON → keymap JSON → InstrumentRegistry во время выполнения

ДВИГАТЕЛЬ ПРОСТЫМИ СЛОВАМИ

ChameleonDrummer строит барабанные треки как музыкальный директор с сессионной группой. Он выбирает паттерны для каждого такта на основе интенсивности, избегает повторов, вставляет филы в структурных точках и применяет специфичные для барабанщика модификации стиля — все из простых текстовых файлов, которые вы можете редактировать.

Формат паттерна (Что Вы Можете Редактировать)

Грувы и филы находятся в config/grooves/.tab и config/fills/.tab. Каждый блок имеет заголовок, объявляющий стиль, размер и интенсивность, за которым следуют строки инструментов с простыми символами :

  • . = пауза (без удара)
  • x = удар
  • X = акцентный удар
  • o = тихая нота
  • g = призрачная нота
  • | = разделитель такта

Пример блока грува из rock.tab :

[rock verse intensity=0.20-0.60]
K  x... .... x... .... | x... .... x... ..x.
S  .... x... .... x... | .... x... .... x...
H  x.x. x.x. x.x. x.x. | x.x. x.x. x.x. x.x.

Как Работает Движок

Для каждого такта движок выбирает грув с помощью взвешенной случайности на основе соответствия интенсивности. Четыре макрофазы (установить, поддерживать, нарастить, завершить) контролируют эволюцию песни. Филь вставляются в структурных точках. Гуманизация добавляет вариации времени и скорости. Физические ограничения предотвращают невозможные паттерны.
