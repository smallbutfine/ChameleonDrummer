Краткий Справочник

  • Команды CLI — chameleondrummer generate --genre metal --style death --tempo 75
  • Использование GUI — Выберите жанр, стиль, барабанщика, маппинг, затем нажмите Generate
  • Доступные Опции — chameleondrummer list genres, и т.д.
  • Справочник Формата Паттерна — README.md
  • Нечетные Такты — --time-sig 7/8

Краткий Справочник Формата Паттерна

Блок Грува (config/grooves/<genre>.tab)

[rock verse intensity=0.20-0.60]
K  x... .... x... .... | x... .... x... ..x.
S  .... x... .... x... | .... x... .... x...
H  x.x. x.x. x.x. x.x. | x.x. x.x. x.x. x.x.
  • Заголовок: [style kind intensity=low-high]
  • Инструменты: K=барабан, S=барабанная кровать, H=hi-hat, HO=открытый hi-hat, HP=педаль hi-hat, R=том-рэк, RB=том-бас, C=crash, C2=второй crash, CH=china, SP=splash, T1-T4=томы
  • Шаги: .=пауза, x=удар, X=акцент, o=тихо, g=призрачно
  • Такты: Разделены |; пробелы игнорируются; более короткие строки повторяются

Блок Fill (config/fills/<drummer>.tab)

[bonham_fill_short energy=0.3]
S ... ... ... xxx

Как Работает Движок (Кратко)

  1. Модель паттерна — Каждый такт имеет позицию, инструмент, скорость, длительность, флаги призрачности/акцента
  2. Структура песни — Секции с паттернами, филы, сегментами, смещениями грува
  3. Выбор бар за баром — Взвешенный случайный выбор на основе соответствия интенсивности
  4. Макрофазы — Установить → Поддерживать → Нарастить → Завершить
  5. Филь — Вставляются в структурных точках, соответствие интенсивности
  6. Гуманизация — Джиттер времени, вариация скорости, чувство свинга
  7. Физические ограничения — Макс. 3 удара/шаг, правила координации конечностей
  8. Плагины барабанщиков — 17 барабанщиков применяют специфичные модификации
  9. Система Keymap — JSON отображает названия нот на MIDI ноты (GM, AD2, EZD3, XG, custom)
  10. Экспорт MIDI — SMF Формат 0 с событиями темпа/размера
