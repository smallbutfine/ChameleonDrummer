Введение

ChameleonDrummer — система динамической генерации MIDI для барабанов, построенная на Free Pascal (FPC) с Lazarus Component Library (LCL). Она генерирует реалистичные барабанные паттерны для 5 жанров (Metal, Rock, Jazz, Funk, Electronic) с 32 стилями всего, и 17 личностями барабанщиков. Поддерживает множество MIDI keymap (GM, AD2, EZD3, XG), такты от 2/4 до 32/16 (включая нечётные такты как 3/4, 5/4, 7/8, 9/8, 11/8, 13/8...), внешние файлы grooves/fills/defaults, экспорт сессий REAPER .rpp и Ardour .ardour, и продвинутую гуманизацию, кривые интенсивности, и ограничения физической играемости.

Производится два исполняемых файла:

  • ChameleonDrummer.exe — командная строка
  • chameleondrummer_gui.exe — графический интерфейс (Lazarus/LCL)

Установка

Требования

  • Windows (основная цель; Linux/macOS возможно с FPC/LCL)
  • Free Pascal Compiler (FPC) 3.2.2+
  • Lazarus IDE (опционально, для разработки графического интерфейса)
  • Free Pascal Compiler (FPC) 3.2.2+ (для конвертера tools/midi_to_tab.exe)

Сборка из Исходников

# Исполняемый командной строки
cd B:\dev\github\ChameleonDrummer
"%SystemDrive%\lazarus\fpc\3.2.2\bin\x86_64-win64\fpc.exe" -O2 -Fusrc -Sg -Sc ChameleonDrummer.lpr

# Исполняемый графического интерфейса
cd gui
cmd /c "build_gui.bat < NUL"

Запуск Исполняемого

Оба исполняемых файла автономны. Поместите ChameleonDrummer.exe и chameleondrummer_gui.exe в одну директорию, или ссылайтесь на командную строку из рабочей директории графического интерфейса.

Быстрый Старт

Командная Строка — Сгенерировать Metal Песню

ChameleonDrummer.exe generate --genre metal --style death --tempo 195 --drummer hoglan --mapping ad2 --output death_metal.mid

Командная Строка — Сгенерировать Rock Паттерн в Стиле Bonham

ChameleonDrummer.exe pattern --genre rock --style classic --drummer bonham --output bonham_verse.mid

Командная Строка — Сгенерировать в Нечётном Тактe

ChameleonDrummer.exe generate --genre rock --style classic --time-sig 7/8 --output rock_7_8.mid

Командная Строка — Список Доступных Опций

ChameleonDrummer.exe list genres
ChameleonDrummer.exe list styles --genre jazz
ChameleonDrummer.exe list drummers
ChameleonDrummer.exe list mappings

Графический Интерфейс — Интерактивная Генерация

  1. Запустите chameleondrummer_gui.exe.
  2. Выберите Жанр: metal.
  3. Выберите Стиль: death.
  4. Выберите Барабанщик: hoglan.
  5. Выберите Mapping: ad2.
  6. Установите Темп: 195.
  7. Настройте ползунки Сложность и Гуманизация.
  8. Нажмите Сгенерировать.
  9. Посмотрите вывод в панели лога.

Концепции Генерации MIDI Барабанов

Этот раздел объясняет базовые принципы, полученные из исходного кода (ComposerV2.pas, DrumGenerator.pas, Pattern.pas, Song.pas, MidiIO.pas).

1. Модель Паттерна и Удара (Pattern.pas)

TPattern — контейнер объектов TBeat. Каждый удар имеет:

  • Позиция (Double): Время в ударах (напр. 0.0, 0.5, 1.0). Позиция 1.0 = второй удар, позиция 2.0 = третий удар, и т.д.
  • Инструмент (TDrumInstrument): Барабанный инструмент (бас-барабан, рабочий барабан, хай-хэт, и т.д.). Идентичность инструмента берётся из JSON keymap файла — никакие ноты не захардкожены в Pascal коде.
  • Velocity (Integer): MIDI velocity от 0 (тишина) до 127 (максимум). Это делает некоторые удары громче или тише.
  • Длительность (Double): Длина ноты в удрах. Большинство барабанных ударов очень короткие (~0.1 удров), но некоторые могут быть длиннее для эффекта.
  • GhostNote (Boolean): Тонкая, низкая-velocity нота для groove ощущения. Представьте барабанщика, легко постукивающего по ободу барабана между основными ударами.
  • Accent (Boolean): Акцентированный удар. Так барабанщик ставит акценты на определённых удрах (как рабочий барабан на 2 и 4 в роке).
  • InstrumentPromoted (Boolean): Флаг происхождения. True только когда инструмент этого удара был изменён на месте genre плагином, промоутившим существующий хай-хэт удар в более энергетическую тарелку для высокоэнергетической секции.

2. Модели Песни и Секции (Song.pas)

TSong содержит секции (TSection), каждая со своими паттернами, fills, темпом, и тактом. Секции в стандартном порядке: intro, verse, pre_chorus, chorus, bridge, breakdown, solo, outro.

Каждая секция имеет свои:

  • Темп — скорость в ударах в минуту (BPM). 0 = наследовать темп песни.
  • Такт — временная сигнатура (4/4, 7/8, 5/4, и т.д.). Первое число = ударов в такте, второе = нотное значение получающее один удар.
  • Сложность — насколько вариативны паттерны. Используется только если HasComplexity установлен; нулевые записи наследуют сложность песни.
  • Паттерны по умолчанию — какие grooves/fills движок должен выбирать для этой секции.

Секции хранятся в простых JSON файлах. Можно добавить свои секции, изменить порядок, или дать каждой секции свой темп и такт.

3. Эволюция Паттерна Такт за Тактом (ComposerV2.pas)

TBarSelector.SelectPatternForPhrase выбирает groove для каждого такта взвешенным случайным выбором:

  • Сопоставление интенсивности: Вес каждого groove основан на том, насколько хорошо его полоса интенсивности подходит к интенсивности такта. Grooves, чья полоса содержит интенсивность такта, получают бонус.
  • Взвешивание недавности: Вес предыдущего паттерна снижается до 0.25×, чтобы он мог вернуться, но редко повторяется подряд. Это предотвращает игра одного и того же паттерна такт за тактом.
  • Макро-фазы: Песня развивается в четырёх фазах:
    • mpEstablish (ранние такты): пробует легкие grooves для установки feeling
    • mpMaintain (средние такты): держит то, что работает
    • mpBuild (к кульминации): предпочитает более тяжёлые, интенсивные grooves
    • mpTurnaround (финал): ведёт обратно к началу или chorus
  • Потокобезопасная случайность: Выбор использует TThreadedRandom для согласованных результатов между потоками.

4. Кривые Интенсивности (ComposerV2.pas)

Интенсивность варьируется по песне: intro/verse легче, chorus тяжелее, bridge/breakdown варьируются. Кривая интенсивности управляет выбором паттерна и размещением fills. Типичные кривые:

  • icAscending — становится громче к кульминации
  • icDescending — начинается громко, затихает
  • icPlateau — примерно постоянная интенсивность
  • icDipRise — падает потом поднимается (часто verse-chorus-verse)
  • icSteps — чёткие изменения интенсивности на границах секций

5. Макро-Композитор (ComposerV2.pas)

Макро-фаза смещает выбор паттерна по секции. Четыре фазы (mpEstablish, mpMaintain, mpBuild, mpTurnaround) контролируют, как groove развивается по песне, как музыкальный директор говорящий "начни просто, построй энергию, затем верни домой."

6. Groove Двигатель (ComposerV2.pas)

Grooves загружаются из файлов config/grooves/.tab. Каждый блок объявляет стиль/вид/полосу интенсивности. Двигатель выбирает лучший подходящий groove на такт.

Формат блока groove:

[style kind intensity=low-high]
K  x... .... x... .... | x... .... x... ..x.
S  .... x... .... x... | .... x... .... x...
H  x.x. x.x. x.x. x.x. | x.x. x.x. x.x. x.x.
  • Header: [style kind intensity=low-high]
  • style — напр. metal, rock, jazz, funk, electronic
  • kind — verse, chorus или bridge
  • intensity=low-high — интенсивности такта (0–1), подходящие этому groove, напр. intensity=0.20-0.60
  • Добавить такт после вида: [classic verse 7/8 intensity=0.2-0.7] для нечётных-метровых grooves
  • Строки инструментов: Одна строка на инструмент. Формат: ИНСТРУМЕНТ ШАГ ШАГ ШАГ | ШАГ ШАГ ШАГ
  • K = бас-барабан, S = рабочий барабан, RS = ride короткий, SS = splash, H = хай-хэт, HO = хай-хэт открытый, HP = педаль хай-хэт, R = rack том, RB = бас том, C = crash, C2 = второй crash, CH = china, SP = splash, T1 = том 1, T2 = том 2, T3 = том 3, T4 = том 4
  • Символы шага: . = пауза (нет удара), x = удар, X = акцентированный удар, o = мягкая нота, g = ghost note
  • Пробелы внутри такта игнорируются (только улучшают читаемость)
  • Такты разделены |. Движок использует количество тактов самой длинной строки; более короткие строки повторяют свои такты.
  • Пример (из rock.tab):
[rock verse intensity=0.20-0.60]
K  x... .... x... .... | x... .... x... ..x.
S  .... x... .... x... | .... x... .... x...
H  x.x. x.x. x.x. x.x. | x.x. x.x. x.x. x.x.

7. Система Fills (ComposerV2.pas)

Fills загружаются из config/fills/.tab. Каждый блок объявляет имя/полосу энергии. Двигатель выбирает fill, чья энергия соответствует интенсивности такта на границах секций.

Формат блока fill:

[bonham_fill_short energy=0.3]
S ... ... ... xxx
  • Header: [name energy=0.3]
  • name — напр. bonham_fill_short, peart_fill_odd_7_8
  • energy=0.3 — интенсивность такта (0–1), которой fill лучше всего подходит
  • Тот же формат инструмент/шаг что grooves: Те же символы шага (., x, X, o, g), те же правила разделителя такт/такты.

8. Гуманизация (AdvancedHumanization.pas)

Тайминг и velocity jitter применяются на ноту, масштабируемые настройкой гуманизации. Ghost notes и accents сохраняются.

  • Тайминг jitter: Каждая нота сдвигается вперёд или назад на несколько мс. Достаточно мало для естественного ощущения, достаточно много чтобы избежать "пулемётного" эффекта.
  • Вариация velocity: Некоторые удары немного громче или тише ожидаемого.
  • Swing: Ощущение, где прямые восьмые играются с лёгким соотношением 2:1 или 3:1, как классический рок или фанк groove. Управляется флагом командной строки --swing или слайдером графического интерфейса (0 = прямой, 0.67 = классический 2:1, 1 = 3:1).

Вы контролируете всё это слайдером Гуманизация в графическом интерфейсе (0–1). На 0 — идеально на сетке. На 1 — максимальное feeling.

9. Физические Ограничения (PhysicalConstraints.pas / PatternFixer.pas)

Фиксер паттернов удаляет невозможные удары:

  • Макс 3 удара на одном шаге: Барабанщик не может ударить бас-барабан, рабочий барабан, и два тома одновременно в одном движении.
  • Паттерны координации конечностей:
    • Правая рука: обычно играет crash или ride
    • Левая рука: хай-хэт или ride
    • Правая нога: педаль бас-барабана
    • Левая нога: педаль хай-хэта
  • Это предотвращает генерацию движком паттернов, которые настоящий барабанщик не мог бы сыграть физически.

10. Архитектура Плагинов (PluginRegistry.pas, DrumGenerator.pas)

Жанровые плагины и плагины барабанщиков скомпилированы в исполняемый файл. Каждый барабанщик применяет 2–4 модификации:

  • BehindBeat: Барабанщик играет немного за тактом для relaxed feeling.
  • GhostNotes: Добавляет тонкие rim-shots и тихие ноты.
  • LinearCoordination: Типичные паттерны конечностей для этого барабанщика (напр. характерные бас-барабан-рабочий-барабан паттерны Bonham).
  • ShuffleFeel: Swing feeling специфичный для этого стиля.
  • FillPatterns: Типичный fill словарь для этого барабанщика.

Модификации композируются и применяются по порядку. Жанровые плагины (Metal, Rock, Jazz, Funk, Electronic) определяют типичные полосы интенсивности, какие grooves имеют смысл для стиля, и стандартную структуру песни.

11. Keymap Система (Kit.pas)

MIDI ноты разрешаются через JSON keymap файлы в mappings/. Никакие захардкоженные ноты не существуют в Pascal коде.

  • Keymap файлы мапят имена нот (kick, snare, hi-hat, tom1, crash, и т.д.) на MIDI ноты.
  • Тот же генерационный движок может использовать любой keymap — GM, AD2, EZDrummer 3, Yamaha XG, или пользовательский.
  • Можете редактировать JSON keymap файлы для кастомизации какая нота триггерит какой барабан.

    • Именно поэтому система работает с множеством разных библиотек барабанов и почему графический интерфейс не захардкодил имена барабанов.

12. MIDI Экспорт (MidiIO.pas, MidiParser.pas)

Сырой SMF Format 0 писатель с VLQ кодировкой, tempo/такт meta событиями, совместимый со всеми DAWs и барабанными VSTs.

  • Tracks: Один MIDI трек содержащий все барабанные ноты.
  • Tempo события: BPM изменения по мере прогресса песни.
  • Такт события: Изменения временной сигнатуры.
  • Данные ноты: Высота (какой барабан), velocity, время начала, длительность.

Этот MIDI файл работает с любой DAW (Reaper, Ardour, Ableton, Logic, и т.д.) и любым барабанным VST плагином (EZDrummer, Superior Drummer, Addictive Drums, и т.д.).

Программа Графического Интерфейса

Графический интерфейс (chameleondrummer_gui.exe) линкует движок напрямую — производит точно то же, что инструмент командной строки, без вызова его.

  1. Запустите chameleondrummer_gui.exe.
  2. Выберите жанр, стиль, барабанщик, keymap, темп, сложность, гуманизацию из интерфейса.
  3. Нажмите Сгенерировать — MIDI файл записывается.
  4. Опционально экспортируйте REAPER проект (.rpp) или Ardour сессию (.ardour) рядом.
  5. Dark mode доступен через Вид > Система/Светлый/Тёмный и сохраняется в gui.ini.

Графический интерфейс даёт интерактивный доступ ко всем опциям генерации командной строки плюс визуальную обратную связь:

  • Превью в реальном времени выбранных комбинаций жанр/стиль/барабанщик
  • Динамические контролы секций добавляемые в runtime на основе жанровых дефолтов
  • Dark mode поддержка (скомпилировано только для Windows)
  • Персистентность конфигурации через gui.ini

См. gui/README.md для деталей Lazarus формы, настройки компонентов, и реализации dark mode.

Графический интерфейс также включает кнопку Step Editor открывающую standalone step editor приложение (tools/step_editor/step_editor.exe). Step editor позволяет визуально редактировать барабанные паттерны на step grid, конвертировать MIDI файлы в tab формат, и сохранять паттерны как grooves или fills. См. Step Editor для деталей.

Интеграция REAPER

ChameleonDrummer интегрируется с REAPER через Lua панель (reaper_chameleon/chameleon_panel.lua), которая драйвит командную строку для генерации барабанов и импортирует результаты прямо в ваш REAPER проект.

Установка

  1. Скопируйте директорию reaper_chameleon/ в папку скриптов REAPER.
  2. Откройте REAPER и загрузите chameleon_panel.lua через Actions > Show action list > New > ReaScript.
  3. Панель появляется как док-окно с четырьмя вкладками.

Вкладки

Song Sections

  • Выберите жанр, стиль, барабанщик, mapping, темп, число тактов
  • Сгенерируйте MIDI через командную строку и импортируйте в текущий REAPER проект
  • Экспортируйте REAPER проект (.rpp) рядом с MIDI

Additive Rhythm

  • Введите аддитивную группировку (напр. 3-3-3-3-2-2)
  • Установите grid разрешение (4, 8, 16, 32), темп, барабанщик, интенсивность
  • Сгенерируйте аддитивные ритм паттерны с по-тактовыми временными сигнатурами
  • Опциональный timeline JSON экспорт для REAPER tempo маркеров

Step Editor

  • Загрузите MIDI item из текущего проекта
  • Редактируйте на grid с применением барабанщика (timing/velocity variance)
  • Примените стиль барабанщика к существующим паттернам

Settings

  • Настройте путь исполняемого командной строки
  • Установите дефолтный жанр/стиль/барабанщик/mapping
  • Обновите опции из командной строки list команд

Log

  • Real-time лог вывод командной строки команд
  • Статус сообщения во время генерации

Командная Строка Команды Используемые REAPER Панелью

ChameleonDrummer list genres --json
ChameleonDrummer list styles --genre metal --json
ChameleonDrummer list drummers --json
ChameleonDrummer list mappings --json
ChameleonDrummer generate --genre X --style Y --mapping Z --tempo N --drummer D --drummer-intensity I --bars B --output file.mid
ChameleonDrummer additive-rhythm --grouping "3-3-3-3-2-2" --grid 16 --tempo 120 --mapping gm --drummer bonham --drummer-intensity 0.8 --output file.mid [--write-timeline timeline.json]

Интеграция Ardour

ChameleonDrummer интегрируется с Ardour через Lua панель (ardour/chameleon_panel.lua), драйвящую командной строки для генерации барабанов и импортирующую результаты прямо в вашу Ardour сессию.

Установка

  1. Скопируйте директорию ardour/ в папку скриптов Ardour (обычно ~/.config/ardour/scripts/ Linux, ~/Library/Application Support/Ardour/scripts/ macOS, или %APPDATA%\Ardour\scripts\ Windows).
  2. Откройте Ardour и загрузите chameleon_panel.lua через Window > Scripting > Script Manager > New Script.
  3. Панель появляется как док-окно с четырьмя вкладками.

Вкладки

Song Sections

  • Выберите жанр, стиль, барабанщик, mapping, темп, число тактов
  • Сгенерируйте MIDI через командную строку и импортируйте в текущую Ardour сессию
  • Экспортируйте Ardour сессию (.ardour) рядом с MIDI

Additive Rhythm

  • Введите аддитивную группировку (напр. 3-3-3-3-2-2)
  • Установите grid разрешение (4, 8, 16, 32), темп, барабанщик, интенсивность
  • Сгенерируйте аддитивные ритм паттерны с по-тактовыми временными сигнатурами
  • Опциональный timeline JSON экспорт для Ardour tempo маркеров

Step Editor

  • Загрузите MIDI item из текущей сессии
  • Редактируйте на grid с применением барабанщика (timing/velocity variance)
  • Примените стиль барабанщика к существующим паттернам

Settings

  • Настройте путь исполняемого командной строки
  • Установите дефолтный жанр/стиль/барабанщик/mapping
  • Обновите опции из командной строки list команд

Log

  • Real-time лог вывод командной строки команд
  • Статус сообщения во время генерации

Справочник Команд

Commands:
  generate         Generate a complete song (multi-bar pattern)
  pattern          Generate a single 1-4 bar pattern
  list             List available genres, styles, drummers, or mappings
  info             Show system information

  --style               Style within genre (heavy, classic, swing, ...)

  --complexity <0-1>          Pattern complexity (default: 0.5)
  --humanization <0-1>        Humanization intensity (default: 0.3)
  --swing <0-1>               Swing feel: 0 = straight (default), 0.67 = classic 2:1, 1 = 3:1
  --time-sig             Meter of the song, e.g. 3/4, 5/4, 7/8, 9/8, 11/8, 13/8 (default 4/4)
  --strict-meter              Only use patterns matching --time-sig

  --drummer             Drummer style (e.g., bonham, peart, carey)
  --output              Output MIDI file path
  --reaper, --ardour          With generate: also write .rpp / the .ardour session
  --mapping             Keymap to use: gm (default), ad2, ezd3, xg
  --structure           Song structure from a JSON file (sections with bars, tempo,
                              complexity; optional genre, style, tempo). Command-line
                              genre/style/tempo win over the file. Not with --section.
  --sidecar             Same as --structure (the REAPER sidecar format works)
  --song-map            Read song map JSON for per-bar tempo/meter
  --write-timeline            Write timeline JSON after generation
  --list                List: genres, styles, drummers, mappings
  --json                      Output JSON for list commands
  --grouping             Additive grouping notation (e.g., 3-3-3-3-2-2)
  --grid                   Grid resolution for additive-rhythm (4, 8, 16, 32)
  --drummer-intensity <0-1>   Drummer intensity for additive-rhythm
  --help, -h                  Show this help

Примеры

Сгенерировать полную песню:

ChameleonDrummer.exe generate --genre metal --style death --tempo 195 --drummer hoglan --mapping ad2 --output death_metal.mid

Сгенерировать одиночный паттерн:

ChameleonDrummer.exe pattern --genre jazz --style swing --output swing_verse.mid

Создать REAPER проект:

ChameleonDrummer.exe reaper export --genre rock --style classic --drummer bonham --mapping gm --output rock_classic.rpp

Создать Ardour сессию:

ChameleonDrummer.exe ardour export --genre rock --style classic --drummer bonham --mapping gm --output rock_classic.ardour

Аддитивный ритм паттерн:

ChameleonDrummer.exe additive-rhythm --grouping "3-3-3-3-2-2" --grid 16 --tempo 120 --mapping gm --drummer bonham --drummer-intensity 0.8 --output additive.mid

Продвинутые Функции

Song Maps и Sidecars

Sections (--section): Описывает структуру песни прямо в командной строке, один --section на секцию, в порядке воспроизведения:

ChameleonDrummer.exe generate --genre metal --style death --section intro:4 --section verse:8 --section chorus:8 --section bridge:4 --output song.mid

Sidecar (--sidecar): JSON файл описывающий секции с тактами, темпом, сложностью, опциональными жанр/стиль/темп overrides. Командная строка жанр/стиль/темп побеждают файл.

Song Map (--song-map): JSON файл описывающий по-тактовые темп/такт изменения для сложных прогрессивных песен.

Нечётные Такты

Движок поддерживает такты 2/4 до 32/16. Используйте --time-sig n/d или --segment для указания. Grooves и fills загружаются из .tab файлов объявляющих свой такт в заголовке блока (напр. [metal verse 7/8 intensity=0.40-0.90]).

Ваши Собственные Grooves, Fills и Defaults

Редактируйте файлы в config/:

  • config/grooves/.tab — добавить новые grooves, изменить полосы интенсивности
  • config/fills/.tab — добавить новые fills, изменить уровни энергии
  • config/defaults/.ini — изменить дефолтный темп/стиль/барабанщик
  • config/sections/.json — изменить дефолтную структуру песни

Перекомпиляция не нужна — движок читает эти файлы в runtime.

Порядок Поиска

  1. Папка в переменной окружения CHAMELEON_CONFIG, если задана
  2. %APPDATA%\ChameleonDrummer\config (Linux: ~/.config/ChameleonDrummer/config)
  3. config рядом с программой
  4. ..\config (dev builds)

Конвертация MIDI → Tab

tools/midi_to_tab.exe конвертирует MIDI файл в .tab groove/fill формат. Скомпилировано из Pascal, нет внешних зависимостей.

midi_to_tab.exe input.mid [output.tab]
midi_to_tab.exe input.mid --fill --name bonham_fill --energy 0.6
midi_to_tab.exe input.mid --meter 7/8 --resolution 16
midi_to_tab.exe input.mid --mapping mappings/gm.json --style rock --kind verse

Опции

ОпцияОписание
--fillВывод fill блока вместо groove
--name Имя fill (дефолт: fill)
--energy <0-1>Энергия fill (дефолт: 0.5)
--meter Override такта (дефолт: MIDI meta или 4/4)
--resolution Шаги на четвертную: 4, 8, 16, 32 (дефолт: 16)
--mapping JSON keymap файл (дефолт: встроенная GM map)
--style Имя стиля groove (дефолт: midi)
--kind Вид groove: verse/chorus/bridge (дефолт: verse)
--intensity Полоса интенсивности groove (дефолт: 0.2-0.6)

Вывод с CRLF окончаниями строк, готов для config/grooves/ или config/fills/.

Step Editor

Step Editor (tools/step_editor/step_editor.exe) — standalone графическое приложение для визуального редактирования барабанных паттернов на step grid, конвертации MIDI файлов в .tab groove/fill формат, и управления блоками паттернов в config файлах. Запускается из главного графического интерфейса через кнопку Step Editor, или напрямую.

Запуск Step Editor

  • Из графического интерфейса: Нажмите кнопку Step Editor в тулбаре главного окна.
  • Напрямую: Запустите tools/step_editor/step_editor.exe из корня проекта или директории установки.
  • Из REAPER/Ardour панелей: Вкладка Step Editor в DAW интеграционных панелях запускает редактор с текущим MIDI item загруженным.

Основные Функции

  • Step Grid Редактирование: Визуальная grid с 17 барабанными инструментами (K, S, RS, SS, H, HO, HP, R, RB, C, C2, CH, SP, T1, T2, T3, T4) и настраиваемыми шагами на такт (4, 8, 16, 32, 64).
  • Velocity/Артикуляция Символы: Каждый шаг использует символ: . (пауза), x (нормальный), X (акцент), o (мягкий/ghost), g (ghost). Клик по ячейкам циклит состояния.
  • MIDI → Tab Конвертация: Загрузите MIDI файл (.mid, .midi) и конвертируйте в tab формат через встроенный midi_to_tab.exe с настраиваемым mapping, стилем, видом, интенсивностью, энергией, разрешением, тактом.
  • Tab Файл Загрузка: Загрузите существующие .tab файлы (и ChameleonDrummer config формат, и иностранные tab форматы) для редактирования.
  • Блок Навигация (Config Файлы): Загрузка config файла из config/grooves/ или config/fills/, редактор парсит все паттерн блоки и даёт dropdown селектор с Prev/Next кнопками для навигации между блоками.
  • Блок Редактирование: Редактируйте поля заголовка блока (Стиль, Вид, Интенсивность Low/High) прямо в UI. Изменения отмечаются индикатором *.
  • Хирургическое Сохранение: Сохраняйте отдельные блоки обратно в исходный файл не задевая другие блоки в том же файле.
  • Новые/Удалить Блоки: Добавьте новые пустые паттерн блоки или удалите существующие (с подтверждением).
  • Zoom/Разрешение: Меняйте grid разрешение (8, 16, 32, 64 шагов на такт) и размер страницы.
  • Dark Mode: Авто-детект системной темы (Windows) с ручным override. Все контролы включая grid, combo boxes, status bar themed.
  • Auto-Scaling: Пропорциональное векторное масштабирование всех UI элементов для high-DPI дисплеев.
  • Экспорт: Сохраняйте отредактированные паттерны как новые groove/fill .tab файлы в config директориях.

MIDI → Tab Конвертация

При выборе MIDI файла (.mid, .midi), редактор автоматически запускает midi_to_tab.exe с текущими UI настройками и показывает результат в grid.

Параметры Конвертации (из UI):

  • Mapping: JSON keymap файл (дефолт: встроенная GM).
  • Style: Groove стиль имя (напр. metal, rock, jazz).
  • Kind: Groove вид (verse, chorus, bridge, intro, outro, fill).
  • Intensity: Полоса для grooves (напр. 0.2-0.6).
  • Energy: Уровень для fills (0.1–1.0).
  • Resolution: Шаги на четвертную (4, 8, 16, 32).
  • Meter: Временная сигнатура (напр. 4/4, 7/8, 4/4T для триольного feel).
  • Fill Mode: При включении — вывод fill блока вместо groove.

Сыроый конвертация вывод показан в status log для отладки.

Tab Файл Форматы

Редактор работает с двумя tab форматами:

1. ChameleonDrummer Config Формат (config/grooves/*.tab, config/fills/*.tab)

Множественные паттерн блоки в одном файле, каждый с заголовком:

[metal verse intensity=0.20-0.60]
K   x.x.x.x.x.x.x.x
S   ..x...x...x...x.
HH  x.x.x.x.x.x.x.x
...
|
K   x.x.x.x.x.x.x.x
...

[metal chorus intensity=0.40-0.80]
K   x.x.x.x.x.x.x.x
...

Загрузка config файла, редактор:

  • Парсит все блоки и заполняет блок селектор dropdown.
  • Показывает блок навигацию UI (селектор, Prev/Next, редактируемые header поля).
  • Позволяет хирургическое сохранение отдельных блоков без перезаписи всего файла.

2. Иностранный Tab Формат (один паттерн, нет блок заголовков)

Простой формат только строки инструментов:

K   x.x.x.x.x.x.x.x
S   ..x...x...x...x.
HH  x.x.x.x.x.x.x.x
...

Загружаются как один редактируемый паттерн без блок навигации.

Step Grid Редактирование

  • Клик ячейки для цикла: . → x → X → o → g → .
  • Диапазон выбор: Перетащите для выбора множества ячеек. Используйте Save Pattern As для экспорта только выбранной области.
  • Инструмент аббревиатуры: Фиксированная левая колонка (K, S, RS, SS, H, HO, HP, R, RB, C, C2, CH, SP, T1, T2, T3, T4).
  • Шаг номера: Верхняя строка показывает шаг индекс внутри каждого такта.
  • Такты разделители: Толстые вертикальные линии отмечают такт границы.
  • Страницы: Используйте Prev/Next Page кнопки или Zoom dropdown для навигации больших паттернов.

Блок Управление (Только Config Файлы)

Когда config файл загружен:

  • Блок Селектор: Dropdown показывающий все блоки форматом Style Kind (IntensityLow-IntensityHigh). Модифицированные блоки показывают суффикс *.
  • Prev/Next: Навигация между блоками.
  • Header Поля: Редактируйте Style, Kind, Intensity Low, Intensity High прямо. Изменения помечают блок как модифицированный.
  • Save Block: Пишет только текущий блок обратно в исходный файл (хирургическое сохранение).
  • New Block: Добавляет новый пустой блок (с текущим meter/разрешением) в файл.
  • Delete Block: Удаляет текущий блок из файла (требует подтверждения, оставляет минимум один блок).
