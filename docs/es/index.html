LOS PRINCIPIOS DETRÁS DE LA GENERACIÓN DE MIDI

Desde ComposerV2.pas, Pattern.pas, Song.pas, y MidiIO.pas — el código fuente revela un pipeline estructurado:

  1. Modelo de Patrón — Pulsos con posición, instrumento, velocidad, flags de nota fantasma/acento.
  2. Estructura de Canción — Secciones con patrones, fills, segmentos y offsets de groove.
  3. Evolución Bar por Bar — Selección aleatoria ponderada de patrones con bandas de intensidad, fases macro, fills context-aware.
  4. Restricciones Físicas — El fijador de patrones elimina hits imposibles.
  5. Humanización — Variación de tiempo y velocidad para realismo.
  6. Exportación MIDI — Eventos VLQ-encodeados con metadatos BPM/PPQ.
