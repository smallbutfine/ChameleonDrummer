Referencia Rápida Formato de Patrón

Grooves y fills son archivos de texto plano que puedes editar en cualquier editor. No se necesita recompilar.

Bloque Groove (config/grooves/.tab)

[rock verse intensity=0.20-0.60]
K  x... .... x... .... | x... .... x... ..x.
S  .... x... .... x... | .... x... .... x...
H  x.x. x.x. x.x. x.x. | x.x. x.x. x.x. x.x.
  • Cabecera: [style kind intensity=low-high] — ej., [metal verse 7/8 intensity=0.40-0.90]
  • Instrumentos: K=bombo, S=caja, H=hi-hat, HO=hi-hat abierto, HP=pedal hi-hat, R=tom rack, RB=tom bajo, C=crash, C2=segundo crash, CH=china, SP=splash, T1-T4=toms
  • Pasos: .=silencio, x=hit, X=acento, o=suave, g=fantasma
  • Compases: Separados por |; espacios ignorados; líneas más cortas se repiten

Bloque Fill (config/fills/.tab)

[bonham_fill_short energy=0.3]
S ... ... ... xxx
  • Cabecera: [name energy=0.3] — energía coincide con intensidad del compás (0–1)
  • Mismo formato de instrumento/paso que grooves

Cómo Funciona el Motor (En Breve)

  1. Modelo de Patrón — Cada beat tiene posición, instrumento, velocidad, duración, flags ghost/accent
  2. Estructura de Canción — Secciones (intro, verse, chorus, bridge) con tempo, compás, complejidad
  3. Selección Bar-por-Bar — Selección aleatoria ponderada de groove basada en coincidencia de intensidad
  4. Fases Macro — Establecer → Mantener → Construir → Giro (como un director musical)
  5. Fills — Insertados en límites de sección, energía-coincidente con intensidad actual
  6. Humanización — Jitter de timing, variación de velocity, feel de swing
  7. Restricciones Físicas — Máx. 3 hits/paso, reglas de coordinación de extremidades
  8. Plugins de Baterista — 17 bateristas aplican modificaciones específicas (BehindBeat, GhostNotes, etc.)
  9. Sistema Keymap — JSON mapea nombres de nota a notas MIDI (GM, AD2, EZD3, XG, custom)
  10. Exportación MIDI — SMF Formato 0 con eventos tempo/compás, funciona con todos los DAWs/VSTs
