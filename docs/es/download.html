Descargar ChameleonDrummer

ChameleonDrummer está disponible como ejecutables compilados para Windows. El sistema está construido con Free Pascal y Lazarus, lo que lo hace ligero y autocontenido.

GitHub Release

Descarga los ejecutables CLI y GUI más recientes desde la página de releases de GitHub.

Descargar desde GitHub

Requisitos del Sistema

  • Windows 10 o posterior (64-bit)
  • Free Pascal Compiler (FPC) 3.2.2+
  • Lazarus IDE (opcional, para desarrollo)
  • Mínimo 2GB RAM

Instalación

No se requiere instalación. Simplemente descarga el ejecutable y ejecútalo. El sistema es autocontenido.

Para desarrollo, clona el repositorio y ejecuta:

lazbuild ChameleonDrummer.lpr

o

lazbuild gui/chameleondrummer_gui.lpi
