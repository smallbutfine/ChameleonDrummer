CHAMELEONDRUMMER 如何创建您的鼓曲目

来自 ComposerV2.pas、Pattern.pas、Song.pas 和 MidiIO.pas — 源代码揭示了任何音乐家都能理解的结构化管道。

  1. 模式模型 — 具有位置、乐器、速度、幽灵/强调标志的节拍。
  2. 歌曲结构 — 包含模式、填充、片段和鼓点偏移的部分。
  3. 逐小节演变 — 基于强度匹配的加权随机模式选择，宏阶段，情境感知填充。
  4. 物理限制 — 模式修复器删除不可能的击打。
  5. 人性化 — 时间和速度变化以实现真实感。
  6. MIDI 导出 — VLQ 编码事件，包含 BPM/PPQ 元数据。

架构亮点

MIDI 引擎（零依赖）

直接二进制 SMF 格式 0 写入器 • VLQ 编码 • 正确的节奏/拍号元事件 • 兼容所有 DAW 和鼓 VST

模式生成

8 个模板 • 特定于风格的风格定义（5 种风格 × 8 种风格 = 38 种总计） • 模式块声明拍号、强度和乐器行

鼓手插件

所有 17 位鼓手都带有完全可组合的修改支持 • BehindBeat、GhostNotes、LinearCoordination、ShuffleFeel、FillPatterns

动态 Keymap 系统

Pascal 代码中没有硬编码的 MIDI 音符 • 所有音符解析通过 template JSON → keymap JSON → InstrumentRegistry 在运行时完成

引擎的通俗解释

ChameleonDrummer 像一位与录音室乐队合作的音乐总监一样构建鼓曲目。它根据强度为每小节选择模式，避免重复，在段落边界插入填充，并应用特定于鼓手的风格修改 — 所有这些都来自您可以编辑的纯文本文件。

模式格式（您可以编辑的内容）

鼓点和填充位于 config/grooves/.tab 和 config/fills/.tab。每个块都有一个声明风格、拍号和强度的标题，后面跟着使用简单字符的乐器行：

  • . = 休止（无击打）
  • x = 击打
  • X = 强调击打
  • o = 柔和音符
  • g = 幽灵音符
  • | = 小节分隔符

来自 rock.tab 的鼓点块示例：

[rock verse intensity=0.20-0.60]
K  x... .... x... .... | x... .... x... ..x.
S  .... x... .... x... | .... x... .... x...
H  x.x. x.x. x.x. x.x. | x.x. x.x. x.x. x.x.

引擎如何工作

对于每小节，引擎使用基于强度匹配的加权随机选择鼓点。四个宏阶段（建立、保持、构建、转折）控制歌曲的演变。填充在结构点插入。人性化添加时间和速度变化。物理限制防止不可能的模式。
