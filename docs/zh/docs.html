模式格式快速参考

鼓点块 (config/grooves/<genre>.tab)

[rock verse intensity=0.20-0.60]
K  x... .... x... .... | x... .... x... ..x.
S  .... x... .... x... | .... x... .... x...
H  x.x. x.x. x.x. x.x. | x.x. x.x. x.x. x.x.
  • 标题: [style kind intensity=low-high]
  • 乐器: K=鼓, S=军鼓, H=踩镲, HO=开踩镲, HP=踩镲踏板, R=架子鼓, RB=低音鼓, C=碰镲, C2=第二碰镲, CH=中国镲, SP=溅镲, T1-T4=鼓
  • 步骤: .=休止, x=击打, X=强调, o=柔和, g=幽灵
  • 小节: 用 | 分隔; 忽略空格; 较短的行重复

填充块 (config/fills/<drummer>.tab)

[bonham_fill_short energy=0.3]
S ... ... ... xxx

引擎工作原理（简要）

  1. 模式模型 — 每个节拍有位置、乐器、速度、持续时间、幽灵/强调标志
  2. 歌曲结构 — 包含模式、填充、片段、鼓点偏移的部分
  3. 逐小节选择 — 基于强度匹配的加权随机模式选择
  4. 宏阶段 — 建立 → 保持 → 构建 → 转折
  5. 填充 — 插入在段落边界，强度匹配
  6. 人性化 — 时间抖动，速度变化，摇摆感
  7. 物理限制 — 最多 3 次击打/步骤，肢体协调规则
  8. 鼓手插件 — 17 位鼓手应用特定修改
  9. Keymap 系统 — JSON 将音符名称映射到 MIDI 音符 (GM, AD2, EZD3, XG, custom)
  10. MIDI 导出 — SMF 格式 0，带节奏/拍号事件
