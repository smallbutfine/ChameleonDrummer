功能

多风格

金属、摇滚、爵士、Funk、电子 — 每种都有 26 种真实风格。

鼓手模仿

Bonham、Porcaro、Weckl、Chambers、Roeder、Dee、Hoglan、Peart、Rich、Copeland、Carey、Smith、Moon、Watts、Haake、Halpern、DoomBlues。

奇数拍

2/4、3/4、5/4、7/8、9/8、11/8、13/8 … 至 32/16。支持每节拍变化。

外部数据

鼓点、填充、默认值和结构是纯文本/JSON 文件 — 无需重新编译即可编辑。

DAW 集成

导出 MIDI，支持 REAPER .rpp 项目或 Ardour .ardour 会话。

人性化

时间/速度抖动、幽灵音符、摇摆、物理可玩性限制。

生成 MIDI 的原理

来自 ComposerV2.pas、Pattern.pas、Song.pas 和 MidiIO.pas — 源代码揭示了一个结构化的管道。

  1. 模式模型 — 具有位置、乐器、速度、幽灵/强调标志的节拍。
  2. 歌曲结构 — 包含模式、填充、片段和鼓点偏移的部分。
  3. 逐小节演变 — 基于强度匹配的加权随机模式选择，宏阶段，情境感知填充。
  4. 物理限制 — 模式修复器删除不可能的击打。
  5. 人性化 — 时间和速度变化以实现真实感。
  6. MIDI 导出 — VLQ 编码事件，包含 BPM/PPQ 元数据。
