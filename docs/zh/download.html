下载 ChameleonDrummer

ChameleonDrummer 提供 Windows 平台编译的可执行文件。该系统采用 Free Pascal 和 Lazarus 构建，轻量且自成一体。

GitHub 发布

从 GitHub 发布页面下载最新的 CLI 和 GUI 可执行文件。

从 GitHub 下载

系统要求

  • Windows 10 或更高版本（64 位）
  • Free Pascal 编译器 (FPC) 3.2.2
  • Lazarus IDE（可选，用于开发）
  • 最低 2GB 内存

安装

无需安装。只需下载可执行文件并运行即可。该系统自成一体。

对于开发，请克隆仓库并运行：

lazbuild ChameleonDrummer.lpr

或

lazbuild gui/chameleondrummer_gui.lpi
