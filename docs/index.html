THE PRINCIPLES BEHIND MIDI GENERATION

From ComposerV2.pas, Pattern.pas, Song.pas, and MidiIO.pas — the source code reveals a structured pipeline:

  1. Pattern Model — Beats with position, instrument, velocity, ghost/accent flags.
  2. Song Structure — Sections with patterns, fills, segments, and groove offsets.
  3. Bar-by-Bar Evolution — Weighted random pattern selection with intensity bands, macro phases, context-aware fills.
  4. Physical Constraints — Pattern fixer removes impossible hits.
  5. Humanization — Timing and velocity variance for realism.
  6. MIDI Export — VLQ-encoded events with BPM/PPQ metadata.
