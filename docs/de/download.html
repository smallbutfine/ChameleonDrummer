ChameleonDrummer ist als kompilierte ausführbare Dateien für Windows verfügbar. Das System ist mit Free Pascal und Lazarus gebaut, was es leichtgewichtig und selbstständig macht.

Systemanforderungen

  • Windows 10 oder später (64-bit)
  • Free Pascal Compiler (FPC) 3.2.2+
  • Lazarus IDE (optional, für Entwicklung)
  • Mindestens 2GB RAM

Installation

Keine Installation erforderlich. Lade einfach die ausführbare Datei herunter und führe sie aus. Das System ist selbstständig.

Für Entwicklung, klone das Repository und führe aus:

lazbuild ChameleonDrummer.lpr

oder

lazbuild gui/chameleondrummer_gui.lpi
