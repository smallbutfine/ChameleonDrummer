Schnellreferenz

Für sofortige Verwendung, siehe:

  • Kommandozeilenprogramm-Befehle — chameleondrummer generate --genre metal --style death --tempo 75
  • grafische Oberfläche-Verwendung — Genre, Stil, Drummer, Mapping auswählen, dann auf Generieren klicken
  • Verfügbare Optionen — chameleondrummer list genres, chameleondrummer list styles --genre jazz, chameleondrummer list drummers
  • Pattern-Format-Referenz — README.md (vollständige Groove/Fill-Syntax, Meter, Instrumente)
  • Ungerade Meter — --time-sig 7/8, --segment verse:4:100:7/8

Pattern-Format Schnellreferenz

Grooves und Fills sind reine Textdateien, die Sie in jedem Texteditor bearbeiten können. Keine Neukompilierung erforderlich.

Groove-Block (config/grooves/.tab)

[rock verse intensity=0.20-0.60]
K  x... .... x... .... | x... .... x... ..x.
S  .... x... .... x... | .... x... .... x...
H  x.x. x.x. x.x. x.x. | x.x. x.x. x.x. x.x.
  • Header: [style kind intensity=low-high] — z. B. [metal verse 7/8 intensity=0.40-0.90]
  • Instrumente: K=Kick, S=Snare, H=Hi-Hat, HO=Hi-Hat offen, HP=Hi-Hat Pedal, R=Rack Tom, RB=Bass Tom, C=Crash, C2=zweiter Crash, CH=China, SP=Splash, T1-T4=Toms
  • Schritte: .=Pause, x=Hit, X=Akzent, o=weich, g=Geisterschlag
  • Takte: Getrennt durch |; Leerzeichen ignoriert; kürzere Zeilen wiederholen

Fill-Block (config/fills/)

[bonham_fill_short energy=0.3]
S ... ... ... xxx
  • Header: [name energy=0.3] — Energie passt zur Taktintensität (0–1)
  • Gleiches Instrument/Schritt-Format wie Grooves

Wie die Engine funktioniert (Kurz gefasst)

  1. Pattern-Modell — Jeder Schlag hat Position, Instrument, Geschwindigkeit, Dauer, Geister-/Akzent-Flags
  2. Song-Struktur — Abschnitte (Intro, Verse, Chorus, Bridge) mit Tempo, Meter, Komplexität
  3. Bar-für-Bar-Auswahl — Gewichtete zufällige Groove-Auswahl basierend auf Intensitätsübereinstimmung
  4. Makro-Phasen — Etablieren → Beibehalten → Aufbauen → Wendepunkt (wie ein Musikdirektor)
  5. Fills — An Abschnittsgrenzen eingefügt, energie-abgestimmt auf aktuelle Intensität
  6. Humanisierung — Timing-Jitter, Geschwindigkeitsvarianz, Swing-Gefühl
  7. Physische Einschränkungen — Max. 3 Hits/Schritt, Gliederkoordinationsregeln
  8. Drummer-Plugins — 17 Drummer wenden stil-spezifische Modifikationen an (BehindBeat, GhostNotes, etc.)
  9. Keymap-System — JSON mapped Notennamen auf MIDI-Noten (GM, AD2, EZD3, XG, custom)
  10. MIDI-Export — SMF Format 0 mit Tempo/Meter-Events, funktioniert mit allen DAWs/VSTs

Step Editor

Der Step Editor (tools/step_editor/step_editor.exe) ist ein eigenständiger visueller Muster-Editor. Laden Sie MIDI- oder Tab-Dateien, bearbeiten Sie Hits auf einem Step-Grid, ändern Sie Taktart und Zoom, navigieren Sie durch Seiten und speichern Sie Muster als Grooves oder Fills in config/grooves/ oder config/fills/. Er verwendet midi_to_tab.exe für die MIDI → Tab-Konvertierung und unterstützt Dark Mode.
