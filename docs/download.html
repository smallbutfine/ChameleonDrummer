Download ChameleonDrummer

ChameleonDrummer is available as compiled executables for Windows. The system is built with Free Pascal and Lazarus, making it lightweight and self-contained.

CLI Executable

The command-line interface (CLI) version of ChameleonDrummer. Ideal for scripting, automation, and headless generation.

Download CLI

GUI Application

The graphical interface with intuitive controls for generating drum tracks. Includes section management, meter selection and real-time feedback.

Download GUI

System Requirements

  • Windows 10 or later (64-bit)
  • Free Pascal Compiler (FPC) 3.2.2+
  • Lazarus IDE (optional, for development)
  • Minimum 2GB RAM

Installation

No installation required. Simply download the executable and run it. The system is self-contained.

For development, clone the repository and run:

lazbuild ChameleonDrummer.lpr

or

lazbuild gui/chameleondrummer_gui.lpi
