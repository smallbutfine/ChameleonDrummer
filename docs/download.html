Installation

Windows

Run the setup executable. It installs the CLI, the GUI and both tools and adds the install directory to your PATH (optional).

macOS

Unzip the archive and drag chameleondrummer_gui.app to /Applications. The app is not code-signed, so the first launch needs one of these:

  • right-click the app → Open, then confirm, or
  • xattr -dr com.apple.quarantine /Applications/chameleondrummer_gui.app

The command line tool and both helpers are inside the bundle at Contents/MacOS and Contents/Resources/tools.

Linux

tar -xzf ChameleonDrummer<version>-linux-x64.tar.gz
cd linux-x64
./ChameleonDrummer generate --genre rock --style classic

The tarball preserves the executable bit, so the programs run directly after extraction. No installation step is needed.

Requirements

  • Windows 10 or later (64-bit)
  • macOS 10.13 or later (Intel or Apple Silicon)
  • Linux with glibc 2.4+ (x86_64 or ARM)
  • No runtime dependencies — everything is statically linked

Building from source

You need Free Pascal 3.2.2+ and, for the GUI, Lazarus. To build every target at once (Windows, macOS, Linux) you also need the FPC cross-compilers and Inno Setup 6.

./build_all.bat            # all 5 targets, artifacts in Deploy/
./build_all.bat --check    # verify the toolchain only

See the README for the full build documentation.
