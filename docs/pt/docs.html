Referência Rápida Formato de Padrão

Grooves e fills são arquivos de texto plano que você pode editar em qualquer editor. Não é necessário recompilar.

Bloco Groove (config/grooves/<genre>.tab)

[rock verse intensity=0.20-0.60]
K  x... .... x... .... | x... .... x... ..x.
S  .... x... .... x... | .... x... .... x...
H  x.x. x.x. x.x. x.x. | x.x. x.x. x.x. x.x.
  • Cabeçalho: [style kind intensity=low-high] — ej., [metal verse 7/8 intensity=0.40-0.90]
  • Instrumentos: K=bombo, S=caixa, H=hi-hat, HO=hi-hat aberto, HP=pedal hi-hat, R=tom rack, RB=tom baixo, C=crash, C2=segundo crash, CH=china, SP=splash, T1-T4=toms
  • Passos: .=repouso, x=hit, X=acento, o=suave, g=fantasma
  • Compassos: Separados por |; espaços ignorados; linhas mais curtas se repetem

Bloco Fill (config/fills/<drummer>.tab)

[bonham_fill_short energy=0.3]
S ... ... ... xxx
  • Cabecera: [name energy=0.3] — energia coincide com intensidade do compás (0–1)
  • Mismo formato de instrumento/paso que grooves

Como o Motor Funciona (Em Breve)

  1. Modelo de Padrão — Cada batida tem posição, instrumento, velocidade, duração, flags ghost/acento
  2. Estrutura da Música — Seções (intro, verse, chorus, bridge) com tempo, compasso, complexidade
  3. Seleção Barra a Barra — Seleção aleatória ponderada de groove baseada em coincidência de intensidade
  4. Fases Macro — Estabelecer → Manter → Construir → Virar (como um diretor musical)
  5. Fills — Inseridos em limites de seção, energia-coincidente com intensidade atual
  6. Humanização — Jitter de timing, variação de velocidade, feel de swing
  7. Restrições Físicas — Máx. 3 hits/passo, regras de coordenação de membros
  8. Plugins de Baterista — 17 bateristas aplicam modificações específicas (BehindBeat, GhostNotes, etc.)
  9. Sistema Keymap — JSON mapeia nomes de nota para notas MIDI (GM, AD2, EZD3, XG, custom)
  10. Exportação MIDI — SMF Formato 0 com eventos tempo/compasso, funciona com todos os DAWs/VSTs

Step Editor

O Step Editor (tools/step_editor/step_editor.exe) é um editor de padrões visual autônomo. Carregue arquivos MIDI ou tab, edite batidas em uma grade de etapas, altere compasso e zoom, navegue pelas páginas e salve padrões como grooves ou fills em config/grooves/ ou config/fills/. Ele usa midi_to_tab.exe para conversão MIDI → tab e suporta modo escuro.
