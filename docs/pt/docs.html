Referência Rápida Formato de Padrão

Bloco Groove (config/grooves/<genre>.tab)

[rock verse intensity=0.20-0.60]
K  x... .... x... .... | x... .... x... ..x.
S  .... x... .... x... | .... x... .... x...
H  x.x. x.x. x.x. x.x. | x.x. x.x. x.x. x.x.
  • Cabeçalho: [style kind intensity=low-high]
  • Instrumentos: K=bumbo, S=caixa, H=hi-hat, HO=hi-hat aberto, HP=pedal hi-hat, R=tom rack, RB=tom baixo, C=crash, C2=segundo crash, CH=china, SP=splash, T1-T4=toms
  • Passos: .=repouso, x=hit, X=acento, o=suave, g=fantasma
  • Compassos: Separados por |; espaços ignorados; linhas mais curtas se repetem

Bloco Fill (config/fills/<drummer>.tab)

Como o Motor Funciona (Em Breve)

  1. Modelo de Padrão — Cada batida tem posição, instrumento, velocidade, duração, flags ghost/acento
  2. Estrutura da Música — Seções com padrões, fills, segmentos, offsets de groove
  3. Seleção Barra a Barra — Seleção aleatória ponderada baseada na correspondência de intensidade
  4. Fases Macro — Estabelecer → Manter → Construir → Virar
  5. Fills — Inseridos nos limites de seção, energia-correspondente
  6. Humanização — Jitter de tempo, variação de velocidade, feel de swing
  7. Restrições Físicas — Máx. 3 hits/passo, regras de coordenação de membros
  8. Plugins de Baterista — 17 bateristas aplicam modificações específicas
  9. Sistema Keymap — JSON mapeia nomes de nota para notas MIDI (GM, AD2, EZD3, XG, custom)
  10. Exportação MIDI — SMF Formato 0 com eventos tempo/compasso
