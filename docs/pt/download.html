Requisitos do Sistema

  • Windows 10 ou posterior (64-bit)
  • Free Pascal Compiler (FPC) 3.2.2+
  • Lazarus IDE (opcional, para desenvolvimento)
  • Mínimo 2GB RAM

Instalação

Nenhuma instalação necessária. Basta baixar o executável e executá-lo. O sistema é autônomo.

Para desenvolvimento, clone o repositório e execute:

lazbuild ChameleonDrummer.lpr

ou

lazbuild gui/chameleondrummer_gui.lpi
