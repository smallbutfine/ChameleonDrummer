Quick Reference

For immediate usage, refer to:

  • CLI Commands — chameleondrummer generate --genre metal --style death --tempo 75
  • GUI Usage — Select genre, style, drummer, mapping, then click Generate
  • Available Options — chameleondrummer list genres, chameleondrummer list styles --genre jazz, chameleondrummer list drummers
  • Odd Meters — --time-sig 7/8, --segment verse:4:100:7/8

Pattern Format Quick Reference

Grooves and fills are plain text files you can edit in any text editor. No recompilation needed.

Groove Block (config/grooves/.tab)

[rock verse intensity=0.20-0.60]
K  x... .... x... .... | x... .... x... ..x.
S  .... x... .... x... | .... x... .... x...
H  x.x. x.x. x.x. x.x. | x.x. x.x. x.x. x.x.
  • Header: [style kind intensity=low-high] — e.g., [metal verse 7/8 intensity=0.40-0.90]
  • Instruments: K=kick, S=snare, H=hi-hat, HO=hi-hat open, HP=hi-hat pedal, R=rack tom, RB=bass tom, C=crash, C2=second crash, CH=china, SP=splash, T1-T4=toms
  • Steps: .=rest, x=hit, X=accent, o=soft, g=ghost
  • Bars: Separated by |; spaces ignored; shorter lines repeat

Fill Block (config/fills/.tab)

[bonham_fill_short energy=0.3]
S ... ... ... xxx
  • Header: [name energy=0.3] — energy matches bar intensity (0–1)
  • Same instrument/step format as grooves

How the Engine Works (In Brief)

  1. Pattern Model — Each beat has position, instrument, velocity, duration, ghost/accent flags
  2. Song Structure — Sections (intro, verse, chorus, bridge) with tempo, meter, complexity
  3. Bar-by-Bar Selection — Weighted random groove selection based on intensity matching
  4. Macro Phases — Establish → Maintain → Build → Turnaround (like a musical director)
  5. Fills — Inserted at section boundaries, energy-matched to current intensity
  6. Humanization — Timing jitter, velocity variation, swing feel
  7. Physical Constraints — Max 3 hits/step, limb coordination rules
  8. Drummer Plugins — 17 drummers apply style-specific modifications (BehindBeat, GhostNotes, etc.)
  9. Keymap System — JSON maps note names to MIDI notes (GM, AD2, EZD3, XG, custom)
  10. MIDI Export — SMF Format 0 with tempo/meter events, works with all DAWs/VSTs
