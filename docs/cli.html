Command Line Reference

The ChameleonDrummer executable is the full engine without a GUI. It is the fastest way to generate, script and batch-process drum tracks, and it is what the GUI and the DAW panels call under the hood.

Quick start

chameleondrummer generate --genre rock --style classic --tempo 120 --output song.mid
chameleondrummer list genres
chameleondrummer list styles --genre jazz
chameleondrummer list drummers

Commands

CommandWhat it does
generateGenerate a complete song (multi-bar arrangement)
patternGenerate a single 1–4 bar pattern
listList genres, styles, drummers or mappings
infoShow version and capability information
reaper exportWrite a REAPER .rpp project
ardour exportWrite an Ardour .ardour session
additive-rhythmGenerate additive rhythm patterns from a grouping

Options

OptionMeaning
--genre <name>metal, rock, jazz, funk, electronic
--style <name>Style within the genre (see the style list below)
--drummer <name>Drummer whose feel is imitated, e.g. bonham, porcaro, weckl
--tempo <bpm>Tempo in BPM (default: the genre/style value)
--complexity <0-1>Pattern complexity (default 0.5)
--humanization <0-1>Humanization intensity (default 0.3)
--swing <0-1>Swing feel: 0 straight, 0.67 classic 2:1, 1 = 3:1
--time-sig <n/d>Meter of the song, e.g. 3/4, 7/8, 13/8
--time-sig <n/d>TMeter with triplet feel, e.g. 4/4T, 7/8T
--strict-meterOnly use patterns that match --time-sig
--section <n:bars[@bpm]>One song section; repeat in order
--segment <n:bars:bpm:n/d>A section with its own tempo and meter; - for bpm keeps the song tempo
--structure <file>Song structure from JSON (sections with bars, tempo, complexity)
--sidecar <file>Same as --structure; the REAPER sidecar format works
--song-map <file>Per-bar tempo/meter map as JSON
--mapping <name>Keymap: gm (default), ad2, ezd3, xg
--output <file>Output MIDI file path
--reaper, --ardourWith generate: also write <output>.rpp / the <output>.ardour session
--write-timelineWrite a timeline JSON after generation
--list <type>List genres, styles, drummers or mappings
--jsonMachine-readable JSON output for list
--grouping <str>Additive grouping, e.g. 3-3-3-3-2-2 (with additive-rhythm)
--grid <n>Grid resolution for additive-rhythm (4, 8, 16, 32)
--drummer-intensity <0-1>Drummer intensity for additive-rhythm
--help, -hShow the built-in help

Examples

# A doom-metal song at 75 BPM with Hoglan's style
chameleondrummer generate --genre metal --style doom --tempo 75 --drummer hoglan

# Rock in 7/8 with an Addictive Drums 2 keymap
chameleondrummer generate --genre rock --style classic --time-sig 7/8 --mapping ad2

# Per-section tempo and meter changes
chameleondrummer generate --genre jazz --style fusion \
  --section intro:4 --section verse:8@120 --segment bridge:4:-:7/8

# A single 2-bar pattern instead of a full song
chameleondrummer pattern --genre funk --style classic --drummer porcaro

# Also write a REAPER project and an Ardour session
chameleondrummer generate --genre metal --style thrash --reaper --ardour --output song.mid

# Additive rhythm pattern (3-3-3-3-2-2 over 16 steps)
chameleondrummer additive-rhythm --grouping "3-3-3-3-2-2" --grid 16 --tempo 120 --output additive.mid

# Machine-readable output for scripting
chameleondrummer list genres --json

Available styles

GenreStyles
metalheavy, death, power, progressive, thrash, doom, breakdown, metal

Drummers

bonham, porcaro, weckl, chambers, roeder, dee, hoglan, peart, rich, copeland, carey, smith, moon, watts, haake, halpern, doomblues

Keymaps

gm (General MIDI, default), ad2 (Addictive Drums 2), ezd3 (EZdrummer 3), xg (Yamaha XG). You can add your own by dropping a JSON file into the mappings folder next to the program — it shows up in list mappings.
